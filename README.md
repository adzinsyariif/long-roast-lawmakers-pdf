One satirical sentence roasting lawmakers who would regulate AI, crypto and
the internet but cannot convert a file to PDF. `main.py` (Python 3, standard
library only, no network) deterministically writes the sentence to
`/output/entry.txt` as UTF-8 with no trailing newline.

> Lawmakers who want to license every AI model, ban every crypto wallet and rewrite the internet still call their 22-year-old staffer to turn a .docx into a PDF.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
